## Current research

My master's research explores **multi-agent LLM evaluation on Humanity's Last Exam**, focusing on text-only multiple-choice and exact-match tasks. I build and test API-based solver and judge workflows, with dataset filtering, structured JSON outputs, answer checking, result logging, and error analysis. I'm interested in comparing reasoning strategies and making experiments easier to reproduce and interpret.

In 2026, I presented my work on multi-agent reasoning and evaluation at an academic exchange activity in Zhejiang.
